# Weather Application

## Description
A Python-based console weather application that fetches live weather information for a city.

## Features
- Accepts city name from the user.
- Displays current temperature.
- Displays humidity.
- Displays weather condition.
- Handles connection errors.

## Technologies Used
- Python
- Requests library
- JSON
- Open-Meteo API

## How to Run

1. Install the required library:

   pip install requests

2. Run the application:

   python weather_app.py

3. Enter a city name.

## Sample Output

City: Hyderabad
Temperature: 24.0 °C
Humidity: 81 %
Weather Condition: Mainly clear
